# 🕷️ Laba Laba Sunda

Laba-Laba Sunda is a Python-based web crawler designed to efficiently crawl links within a website. Equipped with multi-threading, error handling, and comprehensive reporting.

---

## 📌 Features

- Multi-threading support
- Comprehensive error handling
- Detailed crawling reports
- Easy-to-use command-line interface

---

## 🛠️ Installation

1. Clone this repository

    ```bash
    git clone https://github.com/FreedomSecurity1337/laba-laba-sunda.git
    cd laba-laba-sunda
    ```

2. Install dependencies
   Use pip to install the required dependencies:

    ```bash
    pip install -r requirements.txt
    ```

---

## 💻 Usage

1. Run the `x-crawl.py` script with arguments:

    ```bash
    python3 x-crawl.py <URL_TARGET> <THREAD_COUNT>
    ```

    Example:

    ```bash
    python3 x-crawl.py https://example.com 10
    ```

---

## ⚙️ File Structure

- `x-crawl.py`: The main script for crawling websites
- `requirements.txt`: Dependencies for the project
- `LICENSE`: License information for the project

---

## 📑 Notes

- Ensure Python version 3.8+ is installed.
- All HTTPS requests use SSL Unverified, meaning SSL errors are ignored.
- Use responsibly. Do not use this tool for illegal activities or to harm others.
